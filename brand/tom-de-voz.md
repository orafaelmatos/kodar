# Tom de voz

Escreva como um dev experiente explicaria a um cliente que ele respeita: **claro, direto e caloroso**.

## Slogans

- **Principal:** "Tecnologia com gente por trás." Use sob o logo, no título do site, em assinaturas e no rodapé.
- **Alternativas:**
  - "Codar é com a gente." É um trocadilho com o nome; use em redes sociais e campanhas.
  - "Do código à solução."
  - "Seu negócio, em código."
- Use um slogan por peça, nunca dois juntos.

## Regras

- **Fale com "você"** e use "a gente" para a Kodar. Evite "nós" formal e "prezado cliente".
- **Troque jargão por resultado.** Diga o que o cliente ganha, depois como.
- **Frases curtas.** Uma ideia por frase.
- **Sem emoji** em site, propostas e e-mails. Em redes sociais, no máximo um por post.
- **Caixa alta só nos rótulos** (estilo `label`). Títulos em caixa normal, só a primeira letra maiúscula.
- **Botões dizem a ação** em primeira pessoa do cliente: "Conte seu projeto", "Falar no WhatsApp", "Ver projetos".
- **Sem exagero:** nada de "!!!", "melhor do mercado", "soluções disruptivas" ou "alta performance".

## Assim / Não assim

| Assim | Não assim |
| --- | --- |
| "A gente cria um sistema que faz seus pedidos chegarem sozinhos no estoque." | "Desenvolvemos soluções de integração ERP via API REST." |
| "Seu site fica pronto em 3 semanas. Você acompanha cada etapa." | "Entregamos projetos com metodologia ágil e alta performance." |
| "Não sabe por onde começar? Conta pra gente o problema." | "Solicite já um orçamento sem compromisso!!!" |
| "Você fala direto com quem desenvolve." | "Contamos com uma equipe altamente qualificada." |

## Glossário

| Use | Evite |
| --- | --- |
| IA | AI, inteligência artificial (por extenso, só na primeira menção, se precisar) |
| site | website, web site |
| sistema sob medida | software customizado, solução personalizada |
| automação | RPA, robotização |
| a gente | nós, nossa equipe |
| projeto | job, demanda |
| Kodar (com K maiúsculo no texto) | KODAR, kodar (minúsculo só no logo) |
